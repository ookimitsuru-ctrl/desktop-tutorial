# 自作app の保存ルール

自作アプリのビルド成果物（APK など）は、Google ドライブの **マイドライブ / 自作app** 配下に保存する。
アプリごとにサブフォルダを作り、その中に置く。

- 保存先ルート: [マイドライブ / 自作app](https://drive.google.com/drive/folders/1qhYWNJ2psAEkiOhPaY1KvFojeFvP9jVi)
  （フォルダID: `1qhYWNJ2psAEkiOhPaY1KvFojeFvP9jVi`）

## 運用メモ

- 新しいアプリを追加するときは `自作app/<アプリ名>/` を作ってから成果物を置く。
- 以前は「マイドライブ / 共有」に置いていた。上記2アプリのAPKは `自作app` 配下にコピー済みで、
  「共有」側の元ファイルはまだ残っている（手動で削除が必要）。
- 「共有」フォルダは他人と共有する用途のみに使う。
