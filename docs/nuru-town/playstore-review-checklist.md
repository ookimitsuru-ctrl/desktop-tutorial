# 塗るタウン(Nuru Town) Play ストア審査 準備チェックリスト

対象アプリ: 「塗るタウン」(街並みイラストを自由な色でクリック塗りできるWebアプリ)
アプリ本体: `claude/nurutaun-joygaq` ブランチの `index.html`(外部ライブラリ不使用のHTML/CSS/JSのみ)
配布形態: APK化して Google ドライブ「自作app/塗るタウン！」に保管(`docs/自作app-保存ルール.md` 参照、PR #2)

## アプリの特性(このリポジトリのコードから判明している事実)

- 完全にクライアントサイドのみで動作し、外部通信(fetch/XHR/WebSocket等)は一切行っていない
- Cookie・localStorage・IndexedDB等のデータ永続化コードは含まれていない
- 位置情報・カメラ・マイク・連絡先など、センシティブAPIの呼び出しはない
- 「画像として保存」機能はCanvas→PNGのローカルダウンロードのみで、外部送信はしない
- 収集・送信している個人データは無い

→ この事実に基づき、Data Safety(データセーフティ)は「データを収集していません」で申告できる見込み。ただし実際に**APKへラップした際の実装**(WebViewラッパー側で解析SDKや広告SDKを追加していないか)は本リポジトリの範囲外なので、別途確認が必要。

## 必須対応チェックリスト

### 1. プライバシーポリシー(必須)
- [ ] `privacy-policy.md` の内容を元に、Web上で公開できるURLを用意する(GitHub Pages、Googleサイト等)
- [ ] Play Console の「アプリのコンテンツ」→「プライバシーポリシー」欄にURLを登録
- [ ] ストア掲載ページにもプライバシーポリシーへのリンクを掲載

### 2. データセーフティ フォーム(必須)
- [ ] 「データを収集していません」で申告(上記の理由により該当)
- [ ] APKラッパーに広告SDK/解析SDKを組み込んだ場合はその時点で申告内容を見直す

### 3. コンテンツレーティング(IARC質問票)
- [ ] 暴力・成人向け要素は無いため「全年齢対象」で回答できる見込み

### 4. 権限まわり(APKラッパー側で要確認)
- [ ] AndroidManifest.xml のパーミッションを確認し、`INTERNET`など不要な権限を含めていないか確認(オフライン動作のみなら本来INTERNET権限すら不要)
- [ ] センシティブな権限(位置情報・連絡先等)が誤って追加されていないか確認

### 5. 技術要件(APKラッパー側で要確認)
- [ ] Target API Level が Google Play の最新要件を満たしているか(年1回更新される最小ターゲットSDK要件)
- [ ] 64-bit(arm64-v8a等)アーキテクチャに対応しているか
- [ ] Android App Bundle(.aab)形式でのビルド・提出
- [ ] 実機での動作確認(クラッシュ・ANRが発生しないか)

### 6. ストア掲載情報
- [ ] アプリアイコン(高解像度版含む)
- [ ] フィーチャーグラフィック
- [ ] スクリーンショット(実際の画面と一致させる)
- [ ] タイトル・簡単な説明・詳しい説明(誇大・誤解を招く表現がないこと)
- [ ] キーワードの過剰な詰め込みを避ける

### 7. 開発者アカウント
- [ ] Play Console 開発者アカウントの本人確認が完了しているか

## 未確認・要調査事項(本リポジトリ外)

このリポジトリには Android プロジェクト(build.gradle / AndroidManifest.xml)が存在しないため、以下は別途実物を確認する必要がある。

1. APK化に使用したツール・方式(WebViewラッパー / TWA(Trusted Web Activity) / PWA変換ツール等)
2. AndroidManifest.xml に記載された実際のパーミッション
3. targetSdkVersion / compileSdkVersion の値
4. 広告SDK・解析SDKの有無
