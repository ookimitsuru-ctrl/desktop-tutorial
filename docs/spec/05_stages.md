# 05 ステージ

## 5.1 ステージ設計の原則

1. **リングの形がゲーム性を決める**: オープン（リングアウト有）／柵／壁／破壊壁の組み合わせで、ステージごとに異なる戦い方が生まれるようにする。
2. **背景は戦場を邪魔しない**: リング内は明るく、低彩度・低コントラストの床。キャラクターのシルエットが常に背景から浮き立つこと（キャラのリムライトとの色相差を確保）。
3. **縁が見える**: リングの縁・柵・壁は、どのカメラ角度でも一目で分かる（縁の明確なエッジライン、柵の高さの差）。
4. **負荷予算を守る**（§5.4）。
5. **オリジナル**: 既存作品の特定ステージを想起させる構図・ギミックの組み合わせは避ける。

### 5.2.1 オプション: ステージの境界バリエーション

- 対戦設定で「リングアウト: あり / なし」を選択可能。「なし」の場合、全ての `open` 辺と `breakable` 辺を `wall` として扱う（見た目は変えず、透明な壁）。
- トレーニングでは任意の位置（中央・縁際・壁際・角）から開始できる。

## 5.3 ステージの構成要素

各ステージは次のレイヤーで構成する（[12 §12.6](12_data_formats.md) のデータ形式）。

| レイヤー | 内容 | シミュレーション影響 |
|---|---|---|
| リング定義 | 境界多角形、各辺の種類（open/fence/wall/breakable）、柵の高さ、破壊壁の耐久と破壊後の種類、初期配置 | **あり**（決定論データ） |
| リング床メッシュ | 床面（リングアウト先の地形を含む） | なし |
| 近景 | 柵・壁・破壊壁（破壊前/破壊後の2状態メッシュ、破片） | なし（状態はシミュレーションの `wall_state` を参照して表示） |
| 中景 | 建物・木・岩などの背景物 | なし |
| 遠景 | スカイボックス、遠景カード | なし |
| ライティング | 平行光源1、補助光、ライトマップ、リフレクションプローブ、環境設定 | なし |
| 環境演出 | パーティクル（雨・雪・霧・砂塵・落ち葉）、アニメーション（旗・竹・波） | なし |
| オーディオ | 環境音ループ、BGM ID、リングアウト時の専用SE | なし |

- 判定に関わるのは「リング定義」だけである。見た目のメッシュは自由に作り込んでよいが、**リングの縁の位置は判定データと完全に一致** させる（データ検証ツールで、縁メッシュのエッジとリング定義の辺の誤差 ≤ 1cm を確認する）。

## 5.4 ステージの負荷予算（キャラクター2体を含む画面全体）

| 項目 | Low | Medium | High | Ultra |
|---|---|---|---|---|
| 画面内ポリゴン（ステージのみ） | 40k | 70k | 110k | 160k |
| ドローコール（ステージのみ） | 40 | 60 | 80 | 110 |
| マテリアル数 | ≤ 12 | ≤ 16 | ≤ 20 | ≤ 24 |
| テクスチャメモリ | 48MB | 80MB | 128MB | 192MB |
| リアルタイム影 | なし（ライトマップ＋キャラの丸影） | キャラのみ 1カスケード | キャラ＋近景 2カスケード | 2カスケード高解像度 |
| パーティクル同時数 | 200 | 500 | 1,000 | 2,000 |
| 動く背景物 | 最小限 | 中 | 全て | 全て |

- 背景物は LOD を2段階以上持つ。遠景はカード（ビルボード/板ポリ）で表現。
- ライティングは **LightmapGI でベイク** し、リアルタイムライトは平行光源1つ＋キャラ用リムライト（[09 §9.3](09_art_animation_camera_vfx.md)）に限定する。

## 5.5 ステージ別の詳細

### `harbor` 埠頭の夜
- 床: 濡れたコンクリートに黄色い塗装ライン（リングの縁を示す）。雨粒の波紋はデカール/シェーダーで表現。
- 縁の外: 2m 下が海面。リングアウト時は水しぶき＋水中への沈み込み演出。
- 照明: クレーンの投光器（オレンジ）をキー、港の青い環境光をフィル。
- 環境音: 雨、波、遠くの汽笛（ランダム間隔 20〜40秒）。

### `bamboo` 竹林の石舞台
- 床: 平らな石畳、継ぎ目に苔。
- 柵: 竹を組んだ低い垣（0.7m）。柵越えリングアウトでは竹垣の一部がしなる（演出のみ）。
- 霧: 深度フォグ（Mobile レンダラで使用可能な距離フォグ）で奥行き。
- 光芒: 加算合成のカード（Low では無効）。

### `fort` 雪原の砦跡
- 床: 踏み固められた雪の上に石材。キャラの移動に応じて足跡デカール（最大 64 枚、古いものから消える）。
- 破壊壁: 崩れかけた城壁 2 面。破壊時は石材の破片（演出用の簡易物理、最大 24 個、3秒で沈む）と雪煙。破壊後は 3m 下の雪の斜面へのリングアウトが可能になる。
- 吐く息: キャラの口元に周期的な白い息パーティクル（Medium 以上）。

### `ruins` 砂漠の遺跡
- 床: 砂岩の石畳、ひび割れ。縁から 1.5m 下の砂地。
- 夕日: 低い角度の平行光源による長い影（High 以上）。陽炎は画面上部のみの歪みシェーダー（Ultra のみ）。
- 砂塵: 風下方向へ流れるパーティクル。

### `skyline` 摩天楼ヘリポート
- 床: ヘリポートの H マーキング（円の中心）、誘導灯の点滅。
- フェンス: 全周が破壊可能な金網フェンス（高さ 1.2m、耐久 2）。破壊後は外側のセーフティネットへ落下（リングアウト）。
- 背景: 都市の夜景（遠景カード＋ビルの窓の明滅シェーダー）。

### `temple` 古寺の中庭
- 床: 白砂利に敷石。
- 壁: 築地塀（瓦屋根付き）。壁ヒット時に瓦の小片が落ちる演出。
- 紅葉: 落ち葉パーティクル、ゆっくり舞う。

### `raft` 川の筏
- 床: 丸太を組んだ筏。全体がゆっくり上下・傾く（見た目のみ、振幅 3cm、カメラは追従しない）。
- 縁の外: 川面。リングアウト時は大きな水しぶき。
- 背景: 両岸の森、遠くの滝の音。

### `arena` 大闘技場
- 床: 青いマットに白いライン。大会ロゴ（オリジナル）。
- フェンス: 高さ 0.8m のパッド付きフェンス。柵越えリングアウト（浮き・投げで柵高を超えた場合）が起こりうる。
- 観客: 低ポリのシルエット群（インスタンシング、GPU アニメーション）。KO 時に歓声とフラッシュ。
- 大型ビジョン: 試合中のキャラ名・ラウンド表示（UI と同じ情報、演出用）。

### `lighthouse` 嵐の灯台（ボス）
- 床: 灯台の基部の円形の石の台座、濡れた石。
- 縁の外: 岩礁と荒波。
- 演出: 灯台の回転光が周期的にリングを照らす（ライトの回転は演出のみ）。稲光は 15〜30秒間隔。**「光過敏配慮」ON 時は稲光の明滅を無効化** し、ゆっくりした明るさ変化に置き換える。

## 5.6 ステージ選択と解禁

- 初期解禁: `harbor` `bamboo` `fort` `ruins` `skyline` `temple` `raft` `arena`
- `lighthouse`: アーケードで玄斎を倒すと VS / トレーニングで選択可能になる。
- ステージ選択画面ではリング形状を俯瞰の図で表示する（open=赤線、fence=黄線、wall=白線、breakable=破線）。
- 「ランダム」選択あり。
