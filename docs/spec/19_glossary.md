# 19 用語集

| 用語 | 読み / 英語 | 意味 |
|---|---|---|
| F（フレーム） | frame | 1/60 秒。全ての時間の単位 |
| Tick | tick | シミュレーションの1ステップ（=1F） |
| 発生 | startup | 攻撃判定が初めて出るフレーム番号 |
| 持続 | active | 攻撃判定が出ているフレーム数 |
| 硬直 | recovery | 持続終了後、行動可能になるまでのフレーム数 |
| 全体 | total | 技の開始から行動可能になるまで |
| 有利 / 不利 | advantage / disadvantage | 攻防後に、相手より何F早く（遅く）動けるか。+3 なら自分が 3F 早い |
| 五分 | even | 有利不利 0 |
| ガード硬直 / ヒット硬直 | blockstun / hitstun | ガード・被弾後に動けない時間 |
| ヒットストップ | hitstop | 当たった瞬間に両者が停止する演出時間。有利不利に影響しない |
| カウンター（CH） | counter hit | 相手の行動中に当てること。ダメージと有利が増える |
| 確定反撃（確反） | punish | 相手の技をガードした後の隙に、確実に当たる反撃 |
| 上段 / 中段 / 下段 | high / mid / low | 攻撃の高さ。ガード方法が変わる |
| 特殊中段 | special mid | しゃがみガードでも防げる中段（主に肘など） |
| 三すくみ | — | 打撃は投げに勝ち、投げはガードに勝ち、ガードは打撃に勝つ関係 |
| 横移動 / 回避 | evade / sidestep | 奥・手前への移動。直線技をかわす |
| 直線 / 半回転 / 全回転 | linear / half-circular / full-circular | 攻撃の追尾性。回避に対する当たりやすさ |
| 回避狩り | — | 回避中の相手に回転技を当てること（必ず CH） |
| 投げ抜け | throw escape | 正しい方向＋P+G で投げから逃れること |
| 投げ合い | throw clash | 同時に投げを出して弾き合うこと |
| 連続投げ | chain throw | 複数段の投げ。各段で抜け方向の読み合いがある |
| 浮かせ | launcher | 相手を空中に浮かせる技 |
| 空中コンボ | juggle | 浮いた相手への追撃 |
| 補正 | scaling | コンボ中のダメージ減少 |
| よろけ | stagger | 一定時間動けない状態。レバガチャで短縮できる |
| 崩れ | crumple | ゆっくり崩れ落ちる状態。追撃が確定する |
| レバガチャ | mash | 方向とボタンを素早く連打すること |
| ダウン | knockdown / down | 倒れた状態 |
| 受け身 | tech / ukemi | 着地の瞬間に G で素早く起きること |
| 起き攻め | okizeme | 起き上がる相手への攻め |
| ダウン攻撃 | down attack | ダウン中の相手への攻撃 |
| リングアウト | ring out | リングの外に落ちること。即負け |
| 壁よろけ / 壁張り付き | wall stagger / wall splat | 壁に当たって無防備になる状態 |
| 背向け | back-turned | 相手に背中を向けた状態 |
| 側面 / 背面 | side / back | 相手の横・後ろからの攻撃 |
| 構え | stance | キャラ固有の特殊な姿勢。専用の技が出る |
| 当て身 / 受け流し | reversal / parry | 相手の打撃を捕らえて返す技 |
| ジャスト入力 | just frame | 指定フレームちょうどの入力で強化される仕組み |
| 溜め | charge | ボタン押しっぱなしで強化される技 |
| 連携 | string | ボタンを続けて押して出す一連の技 |
| ディレイ | delay | 連携の次段の入力を遅らせること |
| 立ち途中 | while standing | しゃがみから立ち上がる途中に出す技 |
| 先行入力 | input buffer | 行動可能になる前に入力しておくと、可能になった瞬間に出る仕組み |
| 遡及同時押し | retroactive simultaneous press | 1つ目のボタンの技を出した後、2F 以内の2つ目のボタンで同時押し技に置き換える本作の方式 |
| 押し合い | pushbox | キャラ同士が重ならないための判定 |
| 喰らい判定 / 攻撃判定 | hurtbox / hitbox | 攻撃を受ける範囲 / 攻撃が当たる範囲 |
| 決定論 | determinism | 同じ入力なら必ず同じ結果になる性質 |
| 固定小数点 | fixed point | 整数で小数を表す方式（本作は Q16.16） |
| ロールバック | rollback netcode | オンライン対戦で、遅れて届いた入力に合わせて過去から再計算する方式 |
| スナップショット | snapshot | シミュレーション状態の完全なコピー |
| チェックサム | checksum | 状態から計算する短い値。一致すれば同じ状態とみなす |
| ゴールデンリプレイ | golden replay | 期待結果付きの回帰テスト用リプレイ |
| ベイク | bake | アニメーションなどから判定・移動量を事前計算して保存すること |
| ポーズDSL | pose DSL | 本作のアニメーション記述形式（キーポーズ＋補間の JSON） |
| プレイブック | playbook | キャラごとの AI の戦い方データ |
| 縦切り | vertical slice | 一部の範囲（2キャラ・2ステージ）を製品品質で完成させたもの |
| オーナー | owner | 本プロジェクトの依頼者 |
