# 06 ゲームモードと進行

## 6.1 モード一覧

| モード | 概要 | 解禁 | 優先度 |
|---|---|---|---|
| アーケード | CPU 8戦＋ボス。キャラ別ストーリー | 初期 | 必須 |
| VS | CPU戦 / ローカル2P / CPU観戦 | 初期 | 必須 |
| トレーニング | フレーム表示・録画再生・判定表示付きの練習 | 初期 | 必須 |
| チュートリアル | 12課の段階式レッスン | 初期 | 必須 |
| 技トライアル | キャラ別 20課のコマンド/コンボ課題 | 初期 | 必須 |
| サバイバル | 体力持ち越しの勝ち抜き | アーケード1回クリア | 必須 |
| タイムアタック | アーケードの最速クリア | アーケード1回クリア | 必須 |
| リプレイ | 保存した試合の再生 | 初期 | 必須 |
| ギャラリー | エンディング絵、キャラ設定、BGM 再生 | 初期（中身は解禁制） | 必須 |
| オプション | 全設定（[08 §8.7](08_ui_ux.md)） | 初期 | 必須 |
| オンライン | ルームマッチ / ランクマッチ | v1.x | 任意 |

## 6.2 アーケード

### 6.2.1 構成

| 戦 | 相手 | ステージ | 備考 |
|---|---|---|---|
| 1〜6 | ライバル以外の6人（ボスを除く）をランダムな順で | 相手のホームステージ | 難易度は設定値から戦ごとに段階的に上昇 |
| 7 | **ライバル**（キャラごとに固定、§6.2.3） | `arena` | 戦闘前に掛け合いテキスト |
| 8 | **ミラーマッチ**（自分と同じキャラ・別カラー） | 自分のホームステージ | 「自分の型を映す鏡」として短い掛け合い |
| 9 | **鷹司 玄斎**（ボス） | `lighthouse` | 戦闘前に掛け合いテキスト。ボスAI |

- 玄斎使用時: 1〜7戦目はライバル（月嵐）以外の通常キャラ7人、8戦目はライバル（月嵐）、9戦目はミラーマッチ（玄斎・別カラー・ボスAI、`lighthouse`）とする。
- 各試合は既定ルール（2本先取・45秒）。設定で変更可能。

### 6.2.2 難易度

| 設定 | 1戦目のCPUレベル | 9戦目（ボス）のレベル |
|---|---|---|
| やさしい | 1 | 4（ボス補正なし） |
| ふつう | 2 | 6 + ボス補正 |
| むずかしい | 4 | 7 + ボス補正 |
| 達人 | 6 | 8 + ボス補正 |

- CPU レベル定義は [07 §7.5](07_cpu_ai.md)。
- 負けた場合はコンティニュー可能（回数無制限、コンティニューすると「ノーコンティニュー」の記録は付かない）。コンティニュー時に難易度を1段下げる選択肢を表示する。

## 6.3 VS

- **CPU戦**: キャラ・カラー・ステージ・CPUレベル（1〜8）・ルール（ラウンド数・時間・リングアウト有無）を自由に設定。
- **ローカル2P**: [03 §3.3.2](03_controls_and_input.md) のデバイス割当を経てキャラ選択。2P 対戦の戦績を「プレイヤー名」（任意入力、最大 8 文字）ごとに記録。
- **CPU観戦**: CPU 同士の対戦を観戦。CPU レベル個別設定、試合数（1 / 5 / 連続）。バランス確認用として、結果（勝率）を集計表示できる。
- 試合後: 「再戦」「キャラ選択へ」「リプレイ保存」「メニューへ」。

## 6.4 トレーニング

### 6.4.1 メニュー項目

| カテゴリ | 項目 | 選択肢 |
|---|---|---|
| ダミー | 動作 | 立ち / しゃがみ / ガード（立ち）/ ガード（しゃがみ）/ ランダムガード / 全ガード（段を見て自動）/ CPU（レベル指定）/ 操作（2P コントローラー）/ 録画再生 |
| | ガード後の行動 | なし / 最速 `P` / 最速の確定反撃技 / 投げ / 回避 / 録画スロット再生 |
| | 投げ抜け | しない / 常に / ランダム（50%） |
| | 受け身 | しない / その場 / 横 / 後ろ / ランダム |
| | 起き上がり | 寝っぱなし / その場 / 横転 / 後転 / 起き上がり攻撃 / ランダム |
| | よろけ回復 | しない / 最速 / ランダム |
| | カウンター | 通常 / 常にカウンター（ダミーが常に攻撃中扱い） |
| 録画 | スロット | 5スロット × 最大10秒。録画開始/停止、再生、ループ再生、ランダム再生（選んだスロットから抽選） |
| 表示 | フレームデータ | ON / OFF（技の発生・ガード/ヒット時の有利をヒット/ガードのたびに表示） |
| | 入力履歴 | ON / OFF（[03 §3.6](03_controls_and_input.md)） |
| | 判定表示 | OFF / 攻撃判定 / 喰らい判定 / 両方 / 押し合い含む全て |
| | ダメージ表示 | ON / OFF（最後の技・コンボ合計・補正率） |
| | 状態表示 | ON / OFF（両者の現在状態名と経過フレーム） |
| | 有利フレーム常時表示 | ON / OFF（両者が行動可能になるまでの残りフレームをバーで表示） |
| 状況 | 体力 | 自動回復 / 固定値 / 減ったまま |
| | 開始位置 | 中央 / 縁際（自分が背負う）/ 縁際（相手が背負う）/ 壁際（各）/ 角 |
| | ステージ | 全ステージ |
| | 速度 | 1.0 / 0.5 / 0.25 倍（演出だけでなくシミュレーションを低速化。フレーム送り可） |
| その他 | 位置リセット | ボタン1つで即座に開始位置へ戻す（ゲームパッドは Back、タッチは画面上部のアイコン） |
| | 技表 | ポーズからコマンドリストを表示、技を選んで「お手本再生」（ダミーが実演） |

### 6.4.2 フレームデータ表示の仕様

- ヒット/ガードの直後に、画面上部中央に以下を1行で表示し、次のヒット/ガードまで残す。
  `発生 13F ｜ ガード -3F ｜ 中段 ｜ 6P 中段逆突き`
- 有利不利は「両者が実際に行動可能になったフレームの差」を **実測** して表示する（データの値ではなく実測値。これにより Q6 の検証にも使える）。
- 確定反撃練習: 「ガード後の行動」を「最速の確定反撃技」にすると、ダミーが自キャラの技に対する最適反撃を実演する（AI の反撃テーブルを使用）。

## 6.5 チュートリアル（12課）

各課は「説明（テキスト＋お手本動画再生）→ 実践課題 → 合格」で構成。課題は 3回成功で合格。全課をスキップ可能。

| 課 | タイトル | 学ぶこと | 合格条件 |
|---|---|---|---|
| 1 | 操作の基本 | スティック・P/K/G・タッチ操作の練習 | 指示された入力（P、K、G、6P、2K）を順に成功 |
| 2 | 移動 | 歩き・ダッシュ・バックダッシュ・しゃがみ | 指定位置まで移動、ダッシュで間合いを詰める |
| 3 | 攻撃と連携 | 単発技、連携（P,P,K） | ダミーに連携を当てる |
| 4 | ガード | 立ちガード、しゃがみガード、上段はしゃがみでかわせる | ダミーの上段をしゃがんでかわす、中段を立ちガード |
| 5 | 上中下段 | 中段は立ち、下段はしゃがみでガード | ダミーのランダムな中段/下段を5回連続ガード |
| 6 | 投げ | 投げはガードに勝つ、しゃがみに当たらない | ガードを固めたダミーを投げる |
| 7 | 投げ抜け | 抜け方向を読む | ダミーの投げを 3回抜ける（方向は案内あり→なし） |
| 8 | 横移動 | 直線技を回避、回転技には当たる | ダミーの直線技を回避して反撃 |
| 9 | 有利と不利 | ガード後の不利、ヒット後の有利、打撃＞投げ | ガードさせて有利な技の後に投げ／打撃を通す |
| 10 | 確定反撃 | ガード後の大きな隙に反撃 | ダミーの -13F 技をガードして `立ちP` 浮かせで反撃 |
| 11 | 浮かせとコンボ | 浮かせ技からの空中コンボ | 基本コンボを成功 |
| 12 | ダウン・壁・リングアウト | 受け身、起き上がり、壁ヒット、リングアウト | 受け身を取る、縁際で相手を押し出す |

- チュートリアルは灯真を使用（他キャラも選択可、その場合はキャラ固有技に置き換えた課題を自動生成: 課題は技の「カテゴリ」で指定し、`moves.json` のタグから技を選ぶ）。

## 6.6 技トライアル

- キャラ別 20課: 1〜8 単発・連携、9〜14 状況別の確定反撃と崩し、15〜20 コンボ（基本→壁→最大）。
- 課題データは `data/characters/<id>/trials.json`（[12 §12.8](12_data_formats.md)）。
- お手本再生（ダミーが実演、入力表示付き）。
- 全20課クリアでそのキャラのカラー4を解禁。

## 6.7 サバイバル

- CPU と連続で1ラウンド勝負。体力は持ち越し、勝利ごとに 15% + 残り時間 × 0.5% 回復。
- CPU レベルは 5勝ごとに +1（最大 8）、30人目以降はレベル 8 固定。
- 記録: 勝ち抜き数、撃破タイム。

## 6.8 タイムアタック

- アーケード（9戦）を1ラウンド制で戦い、合計クリア時間を競う（演出スキップ時間は除外し、対戦中の時間のみ合計）。
- 難易度は「ふつう」固定。

## 6.9 リプレイ

- **自動保存**: 直近 50 試合を自動保存（古いものから削除）。お気に入り登録したものは削除しない（最大 100）。
- **保存内容**: ゲームバージョン、データハッシュ、乱数シード、キャラ/カラー/ステージ/ルール、全フレームの入力（[12 §12.9](12_data_formats.md)）。1試合あたり数KB。
- **再生機能**: 再生 / 一時停止 / 0.25〜2倍速 / フレーム送り / ラウンド頭出し / 入力表示 / フレームデータ表示 / 判定表示 / フリーカメラ（タッチでドラッグ回転・ピンチでズーム）。
- **互換性**: ゲームデータのハッシュが異なるリプレイは「このバージョンでは再生できません」と表示（決定論の前提が崩れるため）。
- **書き出し**: 共有用にリプレイファイルを書き出し/読み込み（Android の共有シート経由）。

## 6.10 進行・解禁

### 6.10.1 プレイヤー段位

プレイヤー全体の段位（キャラ共通）。対CPU戦（レベル4以上）と2P対戦の勝利でポイントを得る。

| 段位 | 必要ポイント（累計） |
|---|---|
| 10級 → 1級（10段階） | 0, 30, 70, 120, 180, 250, 330, 420, 520, 630 |
| 初段 → 十段（10段階） | 750, 900, 1,080, 1,300, 1,560, 1,860, 2,200, 2,600, 3,050, 3,600 |
| 環闘士（最上位） | 4,500 |

- 獲得ポイント: 勝利 = CPU レベル × 2（2P 対戦は 5）、PERFECT +2、アーケードクリア +20。敗北でポイントは減らない。

### 6.10.2 解禁一覧

| 解禁対象 | 条件 |
|---|---|
| 衣装B | そのキャラでアーケードを（難易度不問で）クリア |
| カラー2 | 初期 |
| カラー3 | そのキャラで CPU 戦 20勝 |
| カラー4 | そのキャラの技トライアル全20課クリア |
| 玄斎（使用） | いずれかのキャラでアーケードを「ふつう」以上でクリア |
| `lighthouse` ステージ | 同上 |
| エンディング絵 | 各キャラでアーケードクリア |
| BGM（ギャラリー） | そのBGMのステージで1回プレイ |
| 称号（プロフィール表示） | 実績（§6.10.3）達成 |

- オプションに「全て解禁」スイッチを用意する（個人プレイ用。ONにすると以後の解禁通知は出ない）。

### 6.10.3 実績（30種、例）

初勝利 / 初PERFECT / 初リングアウト勝ち / 投げ抜け累計100回 / 回避成功累計100回 / 全キャラでアーケードクリア / 達人でノーコンティニュークリア / サバイバル30人抜き / 技トライアル全キャラ制覇 / 10連勝（VS CPU レベル8） ほか。`data/achievements.json` で定義。

## 6.11 セーブデータ

- 保存先: `user://save/`（Android のアプリ専用領域）。
- ファイル: `profile.json`（段位・解禁・実績・記録）、`settings.json`（設定・キー配置・タッチレイアウト）、`replays/*.rbr`。
- 書き込みは「一時ファイルに書いてからリネーム」で原子的に行い、直前の世代を `.bak` として1つ保持する（破損時に自動復旧）。
- 全ファイルに `schema_version` を持ち、起動時にマイグレーション関数で最新形式へ変換する。
- クラウド同期は行わない（Android の自動バックアップ対象にはする: `allowBackup=true`）。
