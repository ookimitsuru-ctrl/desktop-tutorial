# 08 UI/UX

## 8.1 UI の原則

1. **2タップ以内で対戦へ**: タイトルから「クイック対戦（前回の設定で CPU 戦）」まで 2 タップ。
2. **タッチとゲームパッドの両対応**: 全画面がタッチ操作とフォーカスナビゲーション（十字キー/スティック＋決定/戻る）の両方で操作できる。
3. **試合中は情報を最小限に**: HUD は体力・時間・ラウンド数のみ。それ以外の情報（フレーム・入力履歴等）はトレーニングとリプレイ専用。
4. **何が起きたかを伝える**: カウンター、回避成功、投げ抜け、リングアウトを短く明確に表示。
5. **アクセシビリティ**: 色だけに頼らない（形・文字を併用）、文字サイズ変更、点滅の抑制、振動のオン/オフ。

## 8.2 画面遷移

```
起動 → [スプラッシュ: エンジン/ライセンス表記 1秒] → [タイトル]
タイトル ──→ メインメニュー
メインメニュー
  ├─ クイック対戦 ──────────────────────────────→ ロード → 対戦
  ├─ アーケード → 難易度選択 → キャラ選択 → オープニング → [VS画面 → ロード → 対戦 → リザルト]×9 → エンディング → スタッフロール
  ├─ VS → モード選択（CPU / 2P / 観戦）→（デバイス割当）→ キャラ選択 → ステージ選択 → ルール確認 → VS画面 → 対戦 → リザルト
  ├─ トレーニング → キャラ選択（自分・ダミー）→ ステージ選択 → トレーニング
  ├─ チュートリアル → 課選択 → レッスン
  ├─ 技トライアル → キャラ選択 → 課選択 → トライアル
  ├─ サバイバル / タイムアタック → キャラ選択 → 対戦（連続）→ 記録
  ├─ リプレイ → 一覧 → 再生
  ├─ ギャラリー → エンディング / キャラ設定 / BGM / 実績
  ├─ プロフィール → 段位・戦績・称号
  └─ オプション → 各設定
対戦中 [ポーズ] → 再開 / 技表 / 操作設定 / タッチ配置編集 / （トレーニングメニュー）/ リタイア
```

- 全画面で「戻る」（Android の戻る操作・ゲームパッドの B / ○）は1つ前の画面へ。対戦中はポーズ。
- 画面遷移は 200〜300ms のトランジション（スライド＋フェード）。ロード中は「ロード画面」を表示し、最低表示時間は設けない（速ければ即遷移）。

## 8.3 主要画面の仕様

### 8.3.1 タイトル

- ゲームロゴ（オリジナル）、背景はランダムなキャラ2人が `arena` で構えるリアルタイム3Dシーン（Low プリセットでは静止画）。
- 「画面をタップ / ボタンを押してスタート」。バージョン表記を右下に小さく。

### 8.3.2 メインメニュー

- 左側に縦のメニューリスト（大きなタッチ領域: 高さ 56dp 以上）、右側に選択中のキャラ（プロフィールの「お気に入りキャラ」）の 3D モデルがアイドルモーション。
- 最上段に「クイック対戦」。

### 8.3.3 キャラクター選択

```
┌───────────────────────────────────────────────────────────────────┐
│  P1 [灯真の3Dモデル・構えアニメ]              [P2 の3Dモデル]  P2 │
│  篠宮 灯真  篠宮流 実戦空手  ★★☆☆☆                              │
│                                                                   │
│        [灯真][レナ][ビョルン][ゾー][月嵐]                         │
│        [マリエル][アドリアン][ラヴィ][玄斎🔒][ランダム]           │
│                                                                   │
│  カラー: ● ● ● ●   衣装: A / B           [技表] [決定]            │
└───────────────────────────────────────────────────────────────────┘
```

- キャラアイコンは正方形のバストアップ（オリジナルイラスト or 3Dモデルのレンダリング）。未解禁はシルエット＋鍵。
- 選択中のキャラの 3D モデルは選択した色・衣装で即時に切り替わる（モデルは事前ロード、切替 ≤ 100ms）。
- 2P/CPU 側も同画面で選択（CPU 戦では CPU のキャラとレベル）。

### 8.3.4 ステージ選択

- サムネイル（静止画）グリッド＋リング形状の俯瞰図（[05 §5.6](05_stages.md)）、BGM 選択（ステージ既定 / 任意の解禁済み BGM / ランダム）。

### 8.3.5 VS 画面

- 左右からキャラのポートレート（大きな一枚絵または 3D モデルのクローズアップ）がスライドイン、中央に「VS」、下部にキャラ名・流派・ステージ名。1.5秒（ロードが終わるまで延長、タップでスキップ）。
- この間にステージ・キャラのロードとシェーダーウォームアップ（[13 §13.7](13_performance.md)）を行う。

### 8.3.6 リザルト

- 勝者の勝利ポーズ（3D）＋勝利台詞、試合統計（与ダメージ、最大コンボ、カウンター数、投げ抜け数、回避成功数）、獲得段位ポイント、解禁通知。
- ボタン: 再戦 / キャラ選択 / リプレイ保存 / メニュー。

## 8.4 HUD（対戦中）

```
┌───────────────────────────────────────────────────────────────────────┐
│ 篠宮 灯真  ●○                    ┌────┐                    ○● ゾー・ミン │
│ [██████████████████████▒▒▒░░░]   │ 45 │   [░░░▒▒▒██████████████████]  │
│                                  └────┘                               │
│                                                                       │
│       3 HIT                                         COUNTER           │
│       245                                                              │
└───────────────────────────────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| 体力バー | 画面上部、中央の時間表示から外側へ伸びる。残り体力（キャラ色）、直前の被ダメージ分（白 → 0.6秒後に 0.4秒かけて減る「ディレイ表示」）。残り 30% 以下で赤みを帯び、ゆっくり脈動 |
| 名前・ラウンド | 体力バーの上にキャラ名、ラウンド取得数を丸印（●取得 ○未取得）。引き分けは ◐ |
| 時間 | 中央上部。残り 10秒以下で赤く拡大縮小 |
| コンボ表示 | 攻撃側の画面寄りに「N HIT」と合計ダメージ。コンボ終了 1秒後にフェードアウト |
| 特殊ヒット表示 | 「COUNTER」「回避」(EVADE)「投げ抜け」(BREAK)「壁」(WALL)「背面」(BACK) を攻撃/防御側の画面寄りに短く表示（0.6秒）。全て文字＋固有の形状アイコン（色覚配慮） |
| ラウンドコール | 中央に大きく「ROUND 1」「FIGHT」「K.O.」「RING OUT」「TIME UP」「DRAW」「PERFECT」 |
| ポーズボタン | 右上（タッチ時のみ表示）。誤タップ防止のため、押してから 0.3秒以内に離した場合のみ反応 |
| タッチ操作 | [03 §3.2](03_controls_and_input.md) |

- HUD は `CanvasLayer` で 3D の上に描画。体力バーは `TextureProgressBar` ではなく、ディレイ表示のためカスタム描画（`_draw`）で実装する。
- 全 HUD 要素の表示/非表示を設定可能（スクリーンショット用に「HUD 非表示」モード）。

## 8.5 ビジュアルデザイン

### 8.5.1 カラートークン

| トークン | 用途 | 値（目安） |
|---|---|---|
| `bg_deep` | メニュー背景 | #0B0F1A（深い藍黒） |
| `bg_panel` | パネル | #151B2B（不透明度 92%） |
| `accent` | 選択・強調 | #E8452C（朱） |
| `accent_gold` | 上位・称号 | #D4A84B（くすんだ金） |
| `text_primary` | 本文 | #F2F0EA |
| `text_secondary` | 補足 | #A6ABB8 |
| `p1` / `p2` | プレイヤー色 | #3FA7F5（青）/ #F5A53F（橙）※赤緑を避ける |
| `hit_normal` / `hit_counter` / `guard` | 判定の表現（エフェクト） | 白黄 / 朱 / 青白 |
| `danger` | 体力低下 | #E8452C |

### 8.5.2 タイポグラフィ

| 用途 | フォント（全て SIL Open Font License） |
|---|---|
| UI 本文（日本語・英語） | **Noto Sans JP**（Regular / Bold） |
| 見出し・ラウンドコール | **Dela Gothic One**（和文の力強い見出し）＋ 英字見出しは **Oswald**（Bold） |
| 数字（体力・時間・フレーム） | **Oswald**（等幅数字として表示幅を固定） |

- 文字サイズは「標準 / 大 / 特大」（1.0 / 1.2 / 1.4 倍）。最小 12sp 相当。
- フォントはサブセット化（使用文字のみ）して容量を削減する。日本語は JIS 第1・第2水準＋使用漢字を含める。

### 8.5.3 モーション

- ボタン押下: 0.95 倍に縮小（60ms）→ 戻り（120ms、イーズアウト）。
- 選択カーソル: 朱のアウトラインが 0.8秒周期でゆっくり明滅（光過敏配慮 ON 時は静止）。
- ラウンドコールの文字: 拡大から定位置へ（200ms）、筆で払うようなワイプ（シェーダー）。

## 8.6 技表（コマンドリスト）

- ポーズ・キャラ選択・トレーニングから参照可能。
- カテゴリ: 基本技 / 連携 / 特殊技 / 固有システム / 投げ / 回避・背向け / ダウン攻撃。
- 各技: コマンド（アイコン表記）、技名、段、ダメージ、発生、ガード/ヒット時有利（「フレーム表示」ON 時のみ）、短い説明。
- 「お手本」ボタンで、トレーニングのダミーが実演（トレーニング中）または小窓で再生。
- 表示データは `moves.json` から自動生成する（手書きしない）。

## 8.8 ローカライズ

- 全テキストは翻訳キーで管理（`res://i18n/strings.csv`、列: key, ja, en）。コード中に表示文字列を直書きしない。
- 技名は日本語名と英語名を `moves.json` に持つ（例: 刻み突き / Jab Strike）。
- 英語版でもキャラ名の表記は固定（Toma Shinomiya 等）。
- 日本語の禁則処理・ルビは不要（使わない）。

## 8.9 アクセシビリティ要件（必須）

- 全ての重要情報は色＋形状/文字で表現（P1/P2 は青/橙＋「1P」「2P」ラベル）。
- 点滅は 1秒あたり 3回未満（光過敏配慮 OFF 時でも）。大面積の白フラッシュは使わない。
- 光過敏配慮 ON: 稲光・KO フラッシュ・カウンター時の画面フラッシュを無効化し、代わりに縁のビネットで表現。
- 字幕: 勝利台詞・掛け合いは全てテキスト表示。
- 片手操作は対象外（格闘ゲームの性質上）。ただしゲームパッドの全ボタン再割当で補う。
