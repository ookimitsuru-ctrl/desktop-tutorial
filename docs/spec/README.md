# RINGBOUND（仮題）— Android向け 本格3D対戦格闘ゲーム 開発指示書

> 版: v1.0（2026-11-04） / 状態: **確定（実装開始可）**
> 本書一式は、実装者（Claude Code などのAIエージェント、および人間の開発者）が **追加の質問なしに** ゲームを完成まで作り切れることを目的に書かれている。曖昧な点は全て本書の中で決めてある。

---

## 0. この指示書の使い方

- **本書は「決定事項」である。** 実装中に迷ったら本書に従う。本書に書かれていない細部は、[01 ビジョン](01_vision_and_scope.md) の「優先順位の原則」に従って実装者が決め、その決定を `docs/spec/CHANGELOG.md` に1行で記録する。
- **本書を変更する場合**は、変更理由・影響範囲を `docs/spec/CHANGELOG.md` に書いてから本文を直す。数値（フレームデータ等）のバランス調整は `data/` 側を正とし、本書の表は「初期値」とみなす。
- 規範語: **必須**（MUST・守らなければ不合格）／**推奨**（SHOULD・理由があれば外してよい）／**任意**（MAY）。
- 記法: 方向入力はテンキー表記（`6`=前, `4`=後, `2`=下, `8`=上, `3`=前下 …, `N`/`5`=ニュートラル）。ボタンは `P`（パンチ）`K`（キック）`G`（ガード）。詳細は [02 戦闘システム §2.3](02_combat_system.md)。

## 1. 最重要決定事項（1ページ要約）

| 項目 | 決定 |
|---|---|
| タイトル（仮） | **RINGBOUND（リングバウンド）** ／ 副題「闘環」 |
| ジャンル | 3D対戦格闘。3ボタン（P/K/G）＋8方向。上中下段・投げ・横移動（回避）・リングアウト・壁・ダウン攻防。**ゲージ・超必殺技なし**、フレーム有利不利が全て |
| IP方針 | **完全オリジナル。** 「バーチャファイター風」は *ジャンルとメカニクス* として解釈し、既存作品の名称・キャラクター・技名・ステージ・音楽・UI・ロゴ・アナウンス・外観は一切使わない（[18 法務](18_legal_and_assets.md)） |
| エンジン | **Godot Engine 4.5 系 stable**（着手時点の最新 4.x stable に固定し、プロジェクト中は上げない） |
| 言語 | **GDScript（静的型付け必須）**。C#/C++ は使わない |
| レンダラ | Mobile（Vulkan）。非対応端末は Compatibility（OpenGL ES 3）へ自動フォールバック |
| 対応OS / ABI | Android 10（API 29）以上 / arm64-v8a（エミュレータ検証用に x86_64 を追加ビルド可） |
| 画面 | 横画面固定。**シミュレーション60Hz固定・描画60fps固定** |
| ゲームロジック | **自前の決定論的・固定小数点シミュレーション**。Godot の物理エンジンはゲーム判定に使わない（演出のみ） |
| データ駆動 | キャラ・技・ステージ・AI・コンボは JSON。スキーマ検証とフレームデータ自動検証を CI で実施 |
| 入力 | 格闘ゲーム専用設計のタッチ操作 ＋ ゲームパッド（Bluetooth/USB）完全対応 ＋ キーボード（開発用） |
| ロースター | ローンチ **8人 ＋ ボス1人**（全員オリジナル、実在武術ベース） |
| ステージ | **8 ＋ ボス1**（オープン／柵／壁／破壊壁の組み合わせ） |
| モード | アーケード, VS（CPU / ローカル2P）, トレーニング, チュートリアル, 技トライアル, サバイバル, タイムアタック, リプレイ, オプション, ギャラリー。オンライン（ロールバック）は後期フェーズ |
| 配布 | GitHub Actions で APK を自動ビルド → 端末へサイドロード（Google Play 公開は任意の後工程） |
| 品質保証 | GUT による単体/結合テスト、決定論テスト、フレームデータ自動検証、ゴールデンリプレイ回帰、Movie Maker による映像レビュー、実機チェックリスト |
| 収益化 | なし（広告・課金・ガチャ・トラッキング一切なし） |

## 4. 優先順位の原則（判断に迷ったとき）

上ほど優先する。下位の要素のために上位の要素を犠牲にしてはならない。

1. **手触り** — 60fps 安定、入力遅延の最小化、入力の取りこぼしゼロ
2. **公正さ** — ルールの一貫性、表示フレームと実挙動の完全一致、決定論
3. **読み合いの面白さ** — 三すくみ・間合い・有利不利が意味を持つこと
4. **分かりやすさ** — 何が起きたか（ヒット/ガード/カウンター/スカり）が一目で分かる
5. **美しさ** — 絵作り、モーション、演出
6. **コンテンツ量** — キャラ数、技数、モード数
