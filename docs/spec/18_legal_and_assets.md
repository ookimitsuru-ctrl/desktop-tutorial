# 18 法務・IP・アセット管理

> 本章は法的助言ではなく、プロジェクトの運用ルールである。一般公開（Google Play 等）を行う場合は、必要に応じて専門家の確認を受けること。

## 18.1 オリジナリティの確保

「バーチャファイター風」はジャンル・メカニクスの方向性として扱い（[01 §1.4](01_vision_and_scope.md)）、既存作品の表現を使わない。

### 18.1.1 使ってよいもの（ジャンル共通の要素）

- 3D 対戦格闘ゲームの一般的なルール・操作体系（3ボタン、上中下段、投げ、横移動、リングアウト、ダウン攻防、フレーム有利不利など）
- 実在する武術とその一般的な技の名称（正拳突き、裏拳、崩拳、シャッセ、首相撲など）
- 一般的な格闘ゲーム用語・アナウンス（Round、Fight、K.O.、Ring Out、Perfect、Time Up など）

### 18.1.2 使ってはいけないもの

- 既存の格闘ゲーム（バーチャファイター、鉄拳、ストリートファイター、デッド オア アライブ、ソウルキャリバー、その他）の
  - タイトル・ロゴ・商標
  - キャラクターの名前・外見・設定・流派と外見の組み合わせ・決め台詞
  - 作品固有の技名、固有システムの名称
  - ステージの構図・名称・BGM・SE・ボイス・アナウンスの言い回し
  - UI のレイアウト・フォント・配色の模倣
  - 3D モデル・テクスチャ・モーションデータ・判定データ（抽出・トレースを含む）
- 実在の人物（格闘家・俳優など）の名前・肖像

### 18.1.3 命名・デザイン時のチェック手順

1. 新しいキャラクター名・技名（固有名）・ステージ名を決めたら、主要格闘ゲームの登場人物名・固有技名と一致・酷似しないかを検索で確認する。
2. キャラクターのデザイン（シルエット・配色・衣装・流派）が、既存の特定キャラクターを想起させないか確認する（例: 「銀色の金属質の人型ボス」「赤い鉢巻と白い道着の主人公」のような、特定作品の象徴的なデザインの組み合わせは避ける）。
3. タイトル「RINGBOUND」は仮題。一般公開の前に、ゲーム分野での商標・既存タイトルとの重複を確認し、問題があれば変更する。

## 18.2 素材ライセンスの方針

| ライセンス | 可否 | 条件 |
|---|---|---|
| 自作（本プロジェクト用に作成） | ◎ | 作者・作成日を台帳に記録 |
| CC0 / パブリックドメイン | ◎ | 出典 URL を台帳に記録 |
| CC-BY | ○ | クレジット表記（`docs/CREDITS.md` とゲーム内クレジット） |
| MIT / BSD / Apache-2.0 / Zlib（コード） | ○ | ライセンス文をゲーム内のライセンス画面に表示 |
| SIL Open Font License（フォント） | ○ | ライセンス文の同梱・表示、フォント単体での再配布をしない |
| CC-BY-SA | △ | 改変物も同ライセンスになるため、原則として使わない（使う場合は個別に記録） |
| CC-BY-NC / CC-BY-ND / 「非商用のみ」 / ライセンス不明 | ✕ | 使用禁止 |
| 商用利用可の生成ツール（3D・画像・音楽・音声） | ○ | 利用規約（商用利用・再配布・権利帰属）を確認し、規約の該当部分のコピーと利用日を台帳に保存 |
| 他のゲームから抽出した素材 | ✕ | 使用禁止 |

## 18.3 アセット台帳（`docs/ASSET_LEDGER.md`）

全ての外部素材・生成素材を1行ずつ記録する。

| 列 | 内容 |
|---|---|
| パス | リポジトリ内のパス |
| 種類 | model / texture / animation / sfx / bgm / voice / font / code / other |
| 出典 | URL・ツール名・作者 |
| ライセンス | CC0 / CC-BY 4.0 / OFL 1.1 / 自作 / 生成（ツール名） など |
| 取得日 | YYYY-MM-DD |
| 改変 | 加工内容（例: 「トリミング、ピッチ -10%」） |
| クレジット要否 | 要 / 不要 |

- CI の検証で、`assets/` 以下の全ファイルが台帳に記載されていることを確認する（記載漏れでビルド失敗）。

## 18.4 エンジン・ライブラリのライセンス表示

- Godot Engine（MIT）と、エンジンが含むサードパーティのライセンス情報（エンジンの API から取得できる著作権・ライセンス情報）を、オプション → ライセンス画面に全文表示する。
- GUT はテスト専用でリリースビルドに含めない（エクスポートの除外設定）。
- フォント（OFL）、使用した CC-BY 素材のクレジットをクレジット画面とライセンス画面に表示する。

## 18.5 文化的配慮

- 実在の武術・文化を扱うため、敬意を持って描写する。ステレオタイプな誇張（訛りの揶揄、民族衣装の誤用など）を避ける。
- 宗教的なシンボル・聖なる意匠をキャラクターデザインや演出に使わない。
- 実在の国・地域の政治的な対立を想起させる設定を避ける（出身地は実在の地名を使ってよいが、架空の都市を使う場合もある）。
- 武術の名称・用語の表記は、その武術の一般的な表記に従う。

## 18.6 プライバシー

- v1.0 は **データを一切外部送信しない**（ネットワーク権限なし、解析・広告 SDK なし）。
- セーブデータは端末内のみ。ログ（`user://logs/`）は端末内に保存し、オーナーが手動で共有する場合のみ外に出る。
- オンライン（v1.x）を実装する場合は、収集する情報と目的をゲーム内とストア掲載情報で明示する（[14 §14.5](14_online.md)）。

## 18.7 公開する場合（任意の後工程）

- 年齢区分: 流血・残虐表現なしの格闘表現として IARC の質問票に回答する（目安: 12歳以上相当）。
- Google Play: AAB 形式、ターゲット SDK の最新要件、16KB ページサイズ対応、データセーフティの申告、プライバシーポリシーの URL。
- ストアの説明文・スクリーンショットに既存作品の名称を使わない（「〇〇風」等の表現も避ける）。
