# 10 サウンド

## 10.1 方針

1. **打撃音が主役**: 「当たった」「防がれた」「かわした」が目を閉じても分かること。ヒット・ガード・回避・投げ抜け・カウンターの音は互いに明確に異なる帯域とアタック感を持つ。
2. **低遅延**: 打撃音はヒットストップの最初のフレームで鳴り始める。オーディオ出力遅延を最小化する設定を行う（§10.6）。
3. **オリジナル**: BGM・SE・ボイス・アナウンスは全てオリジナルまたは適切なライセンスの素材。既存作品の音・フレーズ・アナウンス文言を模倣しない。

## 10.3 効果音（SE）

### 10.3.1 打撃系（レイヤー構成）

各打撃音は以下の3層を同時に鳴らし、組み合わせで多様性を出す。

| 層 | 内容 | 選択基準 |
|---|---|---|
| インパクト | 打撃の芯（低〜中域の「ドッ」「バシッ」） | 強さ（light/medium/heavy） × 部位（拳/肘/足/頭） |
| ボディ | 当たった側の衣服・肉の音 | 被弾部位（上/中/下）、衣装の材質 |
| スウィッシュ | 空を切る音（攻撃側） | 技の速度・強さ。空振りの時はこれのみ |

| SE | バリエーション数 | 特徴 |
|---|---|---|
| ヒット light / medium / heavy | 各 6 | ピッチ ±4% のランダム、音量 ±1dB |
| カウンターヒット | 4 | ヒットに高域の「キン」という金属的なアクセントと低域の重みを追加 |
| ガード | light / heavy 各 4 | 乾いた短い音、中高域。ヒットより明確に軽い |
| 回避成功 | 3 | 風切り＋布の擦れ。ガードと似ない |
| 投げ（掴み / 叩きつけ / 投げ抜け / 投げ合い） | 各 3〜4 | 投げ抜けは鋭い「パァン」 |
| ダウン（着地 / 受け身） | 各 4 | 床材質で変える（石、木、雪、マット、濡れたコンクリート、砂） |
| 壁ヒット / 壁破壊 | 各 3 | 材質別（石壁、竹垣、金網、パッド） |
| リングアウト | ステージ別 1〜2 | 水しぶき、砂、雪、ネット |
| 足音（歩き・ダッシュ・走り） | 材質別 × 4 | アニメーションのイベントで再生 |
| 溜め・ジャスト入力 | 各 2 | 溜めは上昇音、ジャストは鋭い高音 |
| よろけ / 崩れ | 各 2 | |

### 10.3.2 UI

カーソル移動、決定、キャンセル、キャラ決定（キャラ別の短いアクセント）、解禁通知、ポーズ開閉、ラウンドコールのスティンガー。

### 10.3.3 環境音

ステージごとのループ 1〜2（雨、波、風、竹のざわめき、都市の喧騒、観客、川）＋ランダムワンショット（汽笛、鳥、ヘリ、雷鳴）。

- 台詞の文面は `data/story/<id>.json` に日本語・英語で持つ（字幕表示用）。
- 音声収録が用意できない間は、**気合・被弾の非言語ボイスのみ** 実装し、台詞は字幕のみとする（合成音声の使用は、規約で商用・二次利用が許可されたものに限る）。

### 10.4.2 アナウンス

- オリジナルのアナウンサー音声（英語）: 「Round One / Two / Three / Final Round」「Fight!」「K.O.」「Ring Out!」「Time Up」「Draw」「Perfect」「（キャラ名）Wins」「Extra Round」。
- 文言は格闘ゲームで一般的な語のみとし、既存作品特有の言い回し・発音・抑揚の模倣はしない。

## 10.5 ミキシング

| バス | 内容 | 既定音量 | 処理 |
|---|---|---|---|
| Master | 全体 | 80 | リミッター（-1 dBTP） |
| BGM | 音楽 | 70 | 打撃 heavy / KO 時に -4dB のダッキング（アタック 10ms・リリース 300ms） |
| SFX | 効果音 | 85 | 同時発音数の上限 24（優先度の低い足音から間引く） |
| Voice | キャラボイス | 85 | 同一キャラのボイスは同時に1つ（新しいものが優先） |
| Announcer | アナウンス | 85 | 再生中は BGM を -6dB |
| Ambience | 環境音 | 60 | |
| UI | UI 音 | 70 | |

- ラウドネスの目安: BGM 単体 -16 LUFS（積分）、試合中の全体 -14 LUFS 前後。
- 打撃音は 3D 定位（左右）を弱め（パン幅 30%）に適用し、P1/P2 の位置関係を補助的に伝える。距離減衰はしない（常に聞こえる）。

## 10.6 低遅延化と実装

- 短い SE は WAV をインポート時に **QOA 圧縮**（低負荷・小容量）、BGM・環境音は Ogg Vorbis ストリーミング。
- オーディオの出力遅延設定（`audio/driver/output_latency`）は既定 15ms を目標とし、端末で音切れが出る場合のみ自動で 30ms → 45ms へ段階的に上げる（設定画面で手動選択も可）。
- 打撃音は **シミュレーションのイベント（HitConfirmed 等）を受け取った同じフレーム** に再生要求を出す。アニメーションのイベントトラック経由にしない（遅延と二重再生の原因になるため）。足音のみアニメーションのイベントを使う。
- `AudioStreamPlayer` はプールし、試合中に生成しない。`AudioStreamRandomizer` を用いてピッチ・音量・バリエーションの選択を行う。
- オンライン（ロールバック）に備え、同一イベントの重複再生防止（VFX と同じキー）を入れる。

## 10.7 素材の調達先（候補）

| 種類 | 候補 | 条件 |
|---|---|---|
| SE | CC0 の効果音ライブラリ（Kenney の CC0 オーディオ、Freesound の CC0 素材など）、自作の合成（パーカッシブな音の合成・加工） | CC0 推奨。CC-BY は台帳とクレジットで可 |
| BGM | 自作、CC0/CC-BY の楽曲、商用利用可の生成ツール | 同上 |
| ボイス | 収録（ボイスアクター）、規約が明確な合成音声 | 権利者の書面での許諾、規約の保存 |

- 全素材の出典・ライセンス・加工内容を `docs/ASSET_LEDGER.md` に記録する（[18](18_legal_and_assets.md)）。
