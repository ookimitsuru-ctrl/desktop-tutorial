## 4.3 全キャラ必須の技カテゴリ（技設計チェックリスト）

各キャラの技数は **55〜75**（共通動作・被弾モーションを除く）。以下を **全て満たすこと**（データ検証ツールで自動チェックする）。

- [ ] 発生10Fの上段（`P`）とそこからの連携 2系統以上
- [ ] 発生11Fの下段パンチ（`2P`）
- [ ] 発生12〜14Fの中段（または特殊中段）1つ以上
- [ ] 発生14〜16Fの浮かせ技 1つ以上（立ち途中・しゃがみ・構えのいずれからでも可）
- [ ] CH でよろけ・崩れ・浮きのいずれかになる中段 2つ以上
- [ ] ダウンを奪う下段 1つ以上
- [ ] 半回転技: 左カバー・右カバー 各1つ以上、全回転技 1つ以上
- [ ] ガードさせて有利（+1以上）な中段 1つ以上
- [ ] 回避攻撃 2種（`回避中P`、`回避中K`）
- [ ] 背向け技 2種以上
- [ ] 投げ: `P+G`（抜けN）・`6`系・`4`系・下段投げ（抜け2）の各1つ以上、合計通常投げ 4〜8種
- [ ] 側面投げ・背後投げ 各1つ
- [ ] 壁際専用技（壁を背負った相手 or 壁を背負った自分）1つ以上
- [ ] 走り技 2種（`走りP`/`走りK`）＋ 走り投げ 1種
- [ ] ダウン攻撃 2種（`8P`、`2P`）
- [ ] コンボルート: 中浮かせ始動の基本コンボ 2種、壁コンボ 1種を `combos.json` に登録（AI と技トライアルが使う）

## 4.4 技表の読み方

| 列 | 意味 |
|---|---|
| コマンド | [02 §2.3.1](02_combat_system.md) の記法 |
| 段 | 上=上段、中=中段、下=下段、特中=特殊中段、投=投げ、下投=下段投げ、ダ=ダウン攻撃、当=当て身/受け流し |
| ダメ | 基本ダメージ（体力1000中） |
| 発生 | 単発技は技開始からのフレーム。**連携の2段目以降は「前段の発生から何F後に発生するか」** |
| 持続 / 硬直 | [02 §2.12.1](02_combat_system.md) |
| G / H / CH | ガード時 / ヒット時 / カウンター時の有利フレーム。`KD`=ダウン、`浮`=浮き、`よ`=よろけ、`崩`=崩れ、`吹`=吹き飛び、`壁`=壁張り付き |
| 追尾 | 直=直線、半左/半右=半回転（攻撃者から見て左/右をカバー）、全=全回転 |

## 4.5 篠宮 灯真（`toma`）— 篠宮流 実戦空手

### プロフィール

| 項目 | 内容 |
|---|---|
| 年齢 / 出身 | 23歳 / 日本・石川県金沢市 |
| 身長 / 体重 | 178cm / 76kg |
| 性格 | 実直、負けず嫌い、少し不器用。礼を重んじる |
| 動機 | 父が遺した町道場「篠宮道場」を守るため賞金を求める。同時に、父の「一撃必倒」とは違う「一手先を読む空手」を完成させたい |
| 一人称 / 口調 | 俺 / 丁寧語と素の口調が混ざる |
| 決め台詞（例） | 「一手、先に置いておいた」 「押忍。いい組手でした」 |

### ビジュアル

- **シルエット**: 標準体型。片袖を肩までまくった道着、帯の結び目と長い帯端が動きを強調。
- **衣装A**: 白の道着（使い込んで生成り色）、紺の帯（端に朱の刺繍で「篠」）、黒のオープンフィンガー拳サポーター、裸足。
- **衣装B**: 黒の長袖ラッシュガード＋道着の下＋白い拳バンテージ、黒帯を腰に巻く。
- **カラー**: 1 白×紺×朱（基本）、2 黒×赤、3 生成×深緑、4 灰×金。
- **髪**: 短髪の黒、前髪やや長め。汗の表現（勝利時）。
- **声質**: 20代前半男性、張りのある中音。気合は短く鋭い。

### 性能とゲームプラン

- **強み**: 全距離で必要な技が揃い、確定反撃が分かりやすい。`3P`（特殊中段 12F）と `6P` で手堅く固め、`3K` のカウンターでよろけを取る。
- **弱み**: 突出した性能がなく、崩し（中下段の二択）の火力は平均的。
- **固有システム**: **受け（`4P+K`）** — 上段・中段の「パンチ系」攻撃を 3〜12F で受け流し、成功時に自動で反撃（ダメージ 90、相手は背向けよろけ）。蹴り・下段・投げには無効。失敗時の硬直 20F。

## 4.6 レナ・ヴォルコワ（`lena`）— システマ

### プロフィール

| 項目 | 内容 |
|---|---|
| 年齢 / 出身 | 27歳 / 東欧の架空都市「ヴェルスク」 |
| 身長 / 体重 | 168cm / 55kg |
| 性格 | 冷静、皮肉屋、仕事には誠実。呼吸を乱さない |
| 動機 | 元要人警護官。現在はフリーの護衛。大会主催の環財団について調べる依頼を受け、選手として潜入する |
| 決め台詞（例） | 「力を抜いて。……そう、倒れるのが一番楽よ」 |

### ビジュアル

- **シルエット**: 細身、銀色のロングポニーテール（揺れ物）。短いタクティカルジャケット。
- **衣装A**: チャコールグレーのショートジャケット、黒のタートルネック、カーゴパンツ、黒の指ぬきグローブ、軽量ブーツ。
- **衣装B**: 白のスポーツブラ風トップ＋ダークブルーのトレーニングパンツ、テーピング（露出は控えめ・格闘着として自然な範囲）。
- **カラー**: 1 灰×黒×水色（基本）、2 紺×白、3 ワインレッド×黒、4 オリーブ×砂色。
- **声質**: 落ち着いた低めの女性声。

### 性能とゲームプラン

- **強み**: 連携の **ディレイ（遅らせ入力）と分岐** が豊富で、ガードを固める相手を崩しやすい。ダウン中の相手への攻め（ダウン投げ）が強い。
- **弱み**: 軽量級で浮きやすく、一発のダメージが低い。リーチが短い。
- **固有システム**:
  1. **脱力（`P+K+G`）**: 姿勢を落とす構え（1〜20F しゃがみ扱い＝上段無効、投げは通常投げ無効）。最大 60F 維持可能。脱力中に `P`（掌底・中段）、`K`（足刈り・下段）、`6`（滑り込み・相手の側面へ移動）、`G`（解除）。
  2. **ディレイ連携**: 連携の次段の入力を最大 12F 遅らせられる技が多い（`chain_window` が長い）。
  3. **ダウン投げ（`2P+G`、ダウン中の相手へ）**: 寝ている相手を極める（120、受け身不可の追い打ちが多い）。

## 4.15 アーケードのストーリーテキスト

各キャラについて以下を `data/story/<id>.json` に用意する（日本語・英語）。

- オープニング: 1枚絵 ＋ 200字程度
- 7戦目前（ライバル戦）の掛け合い: 2〜4行
- 最終戦前（玄斎）の掛け合い: 2〜4行
- エンディング: 1〜2枚絵 ＋ 300字程度
