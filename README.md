# Smart Run

セガ「アウトラン」風の、ドット絵の疑似3Dドライブゲームです。Androidの横画面で遊べます。
自車は **smart roadster-coupé**（赤）です。真後ろからの実車写真で比率を測ってドット絵にしました。
他車の普通車より一回り小さい、軽自動車くらいの大きさにしています。

- コースは **夏 → 秋 → 冬 → 春** の4つ。チェックポイントを越えると景色が次の季節へ移ります。
- 最後の春のコースは桜並木です。ゴールの先は **花吹雪** になります。
- 遠くの木や車をスプライトの拡大縮小で描く、アウトランと同じ方式で奥行きを出しています。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 右下の小さなハンドル | つかんで回すと曲がります。指を離すと中央に戻ります。右半分のどこを触ってもハンドルを持てます |
| 左下のアクセルペダル（縦長・右側） | 押している間加速します。離すとエンジンブレーキで軽く減速します |
| 左下のブレーキペダル（幅広・左側） | 押している間ブレーキがかかります |

左のペダルは指を滑らせて踏みかえられます。

- 制限時間内に次のチェックポイントまで走ってください。チェックポイントを通過すると時間が加算されます。
- 道からはみ出すと減速します。木や岩、看板にぶつかると「ガガガッ」と擦れて減速します（通り抜けはできません）。前の車に追突するとスピンします。
- 急カーブ（黄色い矢印の標識）では少しブレーキを使ってください。
- 時間切れになっても、10秒以内にタップすればその季節のコースの最初から続けられます。
- 戻るボタン：走行中はポーズします。ポーズ中に押すとタイトルに戻り、タイトルで押すと終了します。

PCのブラウザでも遊べます。操作は ←→ / A・D でハンドル、↑ / W でアクセル、↓ / S / Space でブレーキ、Enter でスタートです。

## APKのインストール

1. GitHub の **Actions** タブで「Build APK」ワークフローの最新の実行を開きます。
2. Artifacts の `shiki-drive-apk` をダウンロードして展開します。
3. `app-release.apk`（または `app-debug.apk`）をAndroid端末に入れてインストールします。
   提供元不明のアプリのインストールを許可する必要があります。

対応OSは Android 7.0（API 24）以降です。

APKはビルドした環境ごとに署名が変わります。別の環境でビルドしたAPKが入っている端末では「アプリはインストールされていません」と表示されることがあります。そのときは古い Smart Run をアンインストールしてから入れ直してください。

## PV

`promo/smart_run_pv.mp4` は30秒の紹介映像です（1920×1080、60fps）。映像も音もゲーム本体の描画とFM音源をそのまま使っています。

撮り直すときは次のようにします。Playwright（Chromium）と ffmpeg が必要です。

```sh
node promo/make_pv.js out          # out/frames/*.png と out/audio.wav を書き出す
ffmpeg -framerate 60 -i out/frames/%05d.png -i out/audio.wav \
  -vf "scale=1920:1080:flags=neighbor,format=yuv420p" -c:v libx264 -tune animation -b:v 6400k \
  -c:a aac -b:a 160k -movflags +faststart -shortest smart_run_pv.mp4
```

カット割りや字幕は `promo/pv_director.js` にあります。乱数を固定しているので、毎回同じ映像になります。

## ビルド方法

```sh
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

Android Studio でこのフォルダを開いて Run してもビルドできます。JDK 17 と Android SDK 34 が必要です。

## 構成

ゲーム本体は HTML5 Canvas（JavaScript、外部ライブラリなし）で書いています。Androidアプリはそれを全画面のWebViewで動かしているだけです。
`app/src/main/assets/index.html` をブラウザで直接開いても遊べます。

画像ファイルや音声ファイルはありません。ドット絵・BGM・効果音はすべて起動時にコードで作っています。BGMは発振器どうしで周波数変調（FM合成）して、アーケードやメガドライブのFM音源のような音色にしています。

| ファイル | 内容 |
| --- | --- |
| `app/src/main/java/.../MainActivity.kt` | WebViewのラッパー（横画面固定・全画面・画面スリープ防止） |
| `assets/js/render.js` | 疑似3D道路の走査線レンダラーと、スプライトの拡大縮小描画 |
| `assets/js/track.js` | コース（カーブ・起伏・季節のつなぎ目）の定義 |
| `assets/js/scenery.js` | 沿道のオブジェクトの配置ルール |
| `assets/js/art_car.js` | 自車 smart roadster-coupé のドット絵（左右の傾きフレーム、ブレーキランプ） |
| `assets/js/art_traffic.js` | 他車（軽自動車・タクシー・トラック・バス・軽トラなど） |
| `assets/js/art_scenery.js` | 沿道のドット絵（ヤシ・紅葉・雪の杉・桜・ゲートなど） |
| `assets/js/art_bg.js` | 空・雲・山・遠景（多重スクロール、季節のクロスフェード） |
| `assets/js/particles.js` | 落ち葉・雪・桜の花びら・花吹雪、タイヤの煙と砂ぼこり |
| `assets/js/hud.js` | 計器、ハンドル、ブレーキペダル、各種画面 |
| `assets/js/audio.js` / `music.js` | エンジン音（3気筒ターボ風）と効果音、FM音源風BGM（ブラス・エレピ・FMベース・ベル・琴・ストリングス） |
| `assets/js/game.js` | メインループ、車の挙動、交通、ゲーム進行 |

### 車の色や幅を変えたいとき

`assets/js/art_car.js` の先頭にある `BODY`（ボディ色。暗い順から明るい順の7色）を書き換えてください。
大きさは同じファイルの `K`（全体の縮尺。今は 0.78）、車幅は `WIDE`（今は 1.12。実車の比率より12%ワイド）で変えられます。当たり判定も見た目の車幅に合わせて変わります。

## クレジット

- BGMはすべてオリジナルです。エンディング曲は日本古謡「さくらさくら」（パブリックドメイン）を編曲しています。
- 「アウトラン」はセガの作品です。このゲームはその雰囲気を参考にしたファンメイドの作品で、セガとは関係ありません。
