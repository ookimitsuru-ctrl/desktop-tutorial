# WORLD STRIKERS（ワールドストライカーズ）

架空の4か国（日本・ヴァルドリア・ソレスタ・ノルデンガルド）で戦う、3Dサッカーゲームの Android アプリです。
横画面でピッチ全面が映る中継カメラ視点で、ワールドカップ（グループリーグ → 決勝・3位決定戦）を戦います。

## 特徴

- **3Dグラフィックス**（Three.js / WebGL2）
  - HDR レンダリング + ブルーム + ACES トーンマッピング + カラーグレーディング、MSAA
  - 2層スタンドの角丸スタジアム、屋根の照明、LED リボンボード、電光看板、VIPボックス
  - 約4.5万人の観客（インスタンス描画）。盛り上がりに応じて立ち上がり、跳ね、マフラーを掲げる。ナイターではカメラのフラッシュ
  - 芝のライン・刈り込みパターン・摩耗をシェーダで解析的に描画（どの解像度でもくっきり）
  - 屋根の影を解析的に計算したくっきりした日照、選手のリアルタイム影、ナイターの四方向の影
  - デイゲーム / サンセット / ナイトゲーム、4つのスタジアム
  - ボールが入ると波打つゴールネット、シュートの軌跡、スライディングの芝しぶき、紙吹雪、花火
- **選手**: 体のパーツごとのインスタンス描画で、手続き的アニメーション（走る・蹴る・スライディング・ヘディング・GKダイブ・セレブレーション・落胆など）
- **試合エンジン**: ボール物理（空気抵抗・カーブ・バウンド・ポスト/ネット）、チームAI（フォーメーション、プレス/カバー/マーク、裏抜け、パス/シュート/ドリブルの判断）、GKのAI（ポジショニング、ダイブ、クロス処理、1対1）、オフサイド、ファウル、イエローカード、各種セットプレー、主審・副審
- **演出**: ゴールセレブレーション、スローモーションのゴールリプレイ、PK戦、優勝セレモニー（トロフィー）
- **サウンド**: 音声ファイルを使わず Web Audio で合成（観客の歓声・手拍子、審判の笛、キック音、ポスト、ネット、メニューBGM）

## 操作

| ボタン | 攻撃時 | 守備時 |
| --- | --- | --- |
| 左側をドラッグ | 移動 / 方向 | 移動 |
| パス | 足元へのパス | 操作選手の切替 |
| スルー | 裏へのスルーパス | プレス（ボール奪取） |
| ロブ | 浮き球 / クロス | — |
| シュート | 長押しで強さを溜めて離す | スライディング |
| ダッシュ | 押している間スプリント | 同左 |

キーボード（開発用）: WASD/矢印 = 移動、J = パス、K = シュート、L = スルー、I = ロブ、Shift = ダッシュ。ゲームパッドにも対応。

## ビルド

必要なもの: JDK 17 以上、Android SDK（compileSdk 35）、Node.js 20 以上

```sh
./gradlew assembleRelease
# → app/build/outputs/apk/release/WorldStrikers-v1.0.0-release.apk
```

Gradle のビルド中に `web/` のゲーム本体（JavaScript）が `npm ci` → `npm run build` で自動的にバンドルされ、
`app/src/main/assets/game/` に配置されます。

GitHub Actions（`.github/workflows/android-build.yml`）でも push のたびに APK がビルドされ、Artifacts からダウンロードできます。
`v*` のタグを push すると Release に APK が添付されます。

APK はリポジトリ内の `app/signing.keystore`（趣味用の共通鍵）で署名しているため、ローカルビルドと CI ビルドを上書きインストールできます。

## 開発

```sh
cd web
npm install
npm run dev                    # assets/game にデバッグビルド
node tools/simtest.mjs 8 240   # AI同士の試合を8試合ヘッドレスで回してスタッツを確認
```

### ディレクトリ構成

```
app/                       Android アプリ（全画面 WebView のホスト）
web/
  src/
    sim/                   試合エンジン（three.js 非依存。Node でもテスト可能）
      ball.js              ボール物理・パス/シュート軌道の逆算
      player.js            選手の運動と状態
      ai.js                チームAI
      keeper.js            GK AI
      match.js             ルールと試合の進行
    render/                3D描画（スタジアム・観客・ピッチ・選手・ボール・ポストエフェクト）
    game/                  アプリの流れ（メニュー、試合ビュー、大会、PK戦、表彰式）
    ui/                    HUD・メニュー・タッチ操作
    audio/                 合成サウンド
    data/                  チーム・選手・フォーメーション
  tools/                   テスト・デバッグ用スクリプト
```

チーム・選手はすべて架空です。
