# OK RACING

鈴鹿サーキットを舞台にした、Android 向け見下ろし型 F1 レーシングシミュレーター。
1990年前後の F1 をイメージした架空チーム「OK RACING」のマシン **OK-90** を操縦します。

- **ハンドル操作なし。** プレイヤーが操作するのはアクセル・ブレーキ・シフトだけで、ステアリングは端末が自動で行う
- 速く走れるか・抜けるかは、アクセルワークとブレーキングのタイミング次第
- コースは実測ベースの鈴鹿(全長 5,807m・18コーナー・高低差約52m・立体交差・ピットレーン)
- ABS / TCS に頼らない物理(複合スリップタイヤ、空力、荷重移動、タイヤ温度・摩耗、燃料重量、雨)
- フリー走行 / タイムアタック(ゴースト)/ 予選 / 決勝(20台・5/10/20/53周・ピットイン)

## 遊び方

| 方法 | 手順 |
|---|---|
| **Android (APK)** | `release/OKRacing-1.0.2-debug.apk` を端末にコピーしてインストール(提供元不明のアプリを許可) |
| **ブラウザ** | `npm run dev` → `http://localhost:8080/` を開く。HTTPS で公開すればホーム画面に追加(PWA)も可能 |
| **単体HTML** | `npm run build` で作られる `dist/index.html` 1ファイルだけで動作 |

### 操作

| 操作 | タッチ | キーボード (PC) |
|---|---|---|
| アクセル | 左下パッドの中央から**左**へスライド (0〜100%) | ↑ |
| ブレーキ | 左下パッドの中央から**右**へスライド (0〜100%) | ↓ |
| シフト | 右下のパドル。**左が DOWN、右が UP** | ← / → (Z / X) |
| ステアリング | 自動 (操作なし) | — |
| ピット | 左上 PIT → タイヤを選ぶと、最終コーナーで自動的にピットレーンへ | I、1〜4 |
| コース復帰 / ポーズ | 左上のボタン | R / P |

- マシンは理想の走行ラインを自動でたどり、前の車に追いつくと空いている側へ自動で並びかけます。立ち上がりのアクセル、スリップストリーム、ブレーキングの遅らせ方が決まれば抜けます。
- 速度が高すぎればコーナーを曲がり切れず、アクセルを開けすぎれば後輪が空転してスピンします (ABS / TCS なし)。
- コース外で動けなくなったり逆を向いたりした場合は、自動でコースへ復帰します。
- 設定で、ペダルの左右入れ替え、指を離した時の挙動、カメラ (進行方向が上/右、北固定) を変更できます。

## 仕様書で「開発時に確定」とされていた項目の決定内容

| 項目 | 決定 |
|---|---|
| ステアリング方式 | 自動操舵 (プレイヤーは操作しない)。追い越し時の進路取りも自動 |
| スライドパッド | 左下に1本。中央がニュートラル、左がアクセル、右がブレーキ (設定で入れ替え可) |
| 指を離したとき | ゼロに戻すを標準(設定で保持も可) |
| 変速の再現 | シフト時間 0.11秒の駆動切れ、オーバーレブになるシフトダウンは拒否 |
| 車両性能 | 約680ps / 13,600rpm、乾燥重量 505kg、最高速 約300km/h、ソフトタイヤで 1分42秒前後 |
| 雨 | 路面の濡れ具合(0〜100%)を連続値で計算。スリックとレインの性能は濡れ約40%で逆転 |

## 開発

```
npm install        # esbuild のみ
npm run dev        # 開発サーバー (ビルド不要、ES Modules のまま動く)
npm test           # 画面なしの自動テスト (コース寸法・車両性能・20台レース)
npm run build      # dist/ に単体版を出力
cd android && gradle assembleDebug   # APK (要 Android SDK。先に npm run build)
```

| パス | 内容 |
|---|---|
| `src/track.js` | コース生成(中心線・幅員・縁石・ランオフ・バリア・高低差・立体交差・ピット) |
| `src/physics.js` | 車両物理、タイヤ4種、セッティング3種 |
| `src/ai.js` | AIドライバー(速度プロファイル、追い越し・防御) |
| `src/race.js` | セッション進行(計時・順位・スタート・ピット・天候・ゴースト) |
| `src/render.js` `src/carsprite.js` `src/hud.js` | 描画 |
| `src/input.js` `src/audio.js` `src/ui.js` `src/storage.js` | 入力・サウンド(合成)・メニュー・保存 |
| `tools/build-track.mjs` `tools/build-line.mjs` | コースデータ変換、最小曲率レーシングラインの事前計算 |
| `android/` | WebView でゲームを全画面表示する Android プロジェクト |

## コースデータとライセンス

- コース中心線・幅員: [TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database) (LGPL-3.0、`third_party/LGPL-3.0.txt`)。中心線の原データは © OpenStreetMap contributors (ODbL)。
- 元データを 5,807m に正規化し、局所的な折れを平滑化(元データとのずれは平均 約0.5m)。高低差は公開情報をもとにした近似プロファイルです。
- コースは現行レイアウトです(1990年当時とは 130R とシケインの形状が異なります)。
- チーム名・ドライバー名・マシンはすべて架空で、実在のチーム・主催者・サーキット運営者とは関係ありません。
