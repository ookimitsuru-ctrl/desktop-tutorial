# Formula simulator

鈴鹿サーキット・富士スピードウェイ・インディ (オーバル) を舞台にした、Android 向け見下ろし型 F1 レーシングシミュレーター。
1990年前後の F1 をイメージした架空チーム「OK RACING」のマシン **OK-90** を操縦します。(ゲームのタイトルは Formula simulator、「OK RACING」は作中の架空チーム名です)

- **ハンドル操作なし。** プレイヤーが操作するのはアクセル・ブレーキ・シフトだけで、ステアリングは端末が自動で行う
- 速く走れるか・抜けるかは、アクセルワークとブレーキングのタイミング次第
- コースは2つ。メニューの「サーキット」で切り替え
  - **鈴鹿サーキット**: 実測ベース(全長 5,807m・18コーナー・高低差約52m・立体交差)
  - **富士スピードウェイ**: コース図から作成(全長 4,563m・16コーナー・メインストレート約1.5km・最大勾配 上り約8%/下り約9%)
  - **インディ スーパースピードウェイ**: コース図の形と諸元から推定(全長 4,023m・ストレート 1,006m・ターン4つ・反時計回りのオーバル。ピットは内側=左。ターンは約9度のバンク付きで、薄いウイングのスーパースピードウェイ仕様になるため、ターン手前でアクセルを戻す必要があります)
- ABS / TCS に頼らない物理(複合スリップタイヤ、空力、荷重移動、タイヤ温度・摩耗、燃料重量、雨)
- フリー走行 / **トレーニング** / タイムアタック(ゴースト)/ 予選 / 決勝(20台・5/10/20/53周・ピットイン)

## 遊び方

| 方法 | 手順 |
|---|---|
| **Android (APK)** | `release/FormulaSimulator-1.3.14-debug.apk` を端末にコピーしてインストール(提供元不明のアプリを許可) |
| **ブラウザ** | `npm run dev` → `http://localhost:8080/` を開く。HTTPS で公開すればホーム画面に追加(PWA)も可能 |
| **単体HTML** | `npm run build` で作られる `dist/index.html` 1ファイルだけで動作 |

### 操作

| 操作 | タッチ | キーボード (PC) |
|---|---|---|
| アクセル | 左下パッドの中央から**右**へスライド (0〜100%) | ↑ |
| ブレーキ | 左下パッドの中央から**左**へスライド (0〜100%) | ↓ |
| シフト | 右下のパドル。**左が DOWN、右が UP** | ← / → (Z / X) |
| ステアリング | 自動 (操作なし) | — |
| ピット | 左上 PIT → タイヤを選ぶと、最終コーナーで自動的にピットレーンへ | I、1〜4 |
| コース復帰 / ポーズ | 左上のボタン | R / P |

- マシンは理想の走行ラインを自動でたどり、前の車に追いつくと空いている側へ自動で並びかけます。立ち上がりのアクセル、スリップストリーム、ブレーキングの遅らせ方が決まれば抜けます。
- 速度が高すぎればコーナーを曲がり切れず、アクセルを開けすぎれば後輪が空転してスピンします (ABS / TCS なし)。
- コース外で動けなくなったり逆を向いたりした場合は、自動でコースへ復帰します。
- 設定で、ペダルの左右入れ替え、指を離した時の挙動、カメラ (進行方向が上/右、北固定) を変更できます。

## トレーニングモード

選んだセッティング・タイヤ・路面で、AIが走った**お手本ラップ**(理想ライン・理想の速度)を先に記録し、それを手本に練習します。

- **お手本ゴースト**: 半透明の青い車が、お手本どおりの速度とラインで先行します (ON/OFF 可)
- **目標パネル(左)**: いまの位置でのお手本の**速度**と**最適ギヤ**(0.4秒先の目標速度で回転が約12,000rpmになるギヤ)を大きく表示。現在値との差、お手本のペダル操作(ブレーキ◯%/全開/リフト)も出ます
- **トレーナーの声かけ**: ブレーキ開始点、ブレーキの離しどき、アクセルを開ける点、ギヤ、空転/ロックをその場で助言。コーナーを抜けるたびに「ブレーキが12m遅い」などの短い講評
- **講評(走り終えたあと)**: お手本との差(秒)と★1〜5・100点満点、ブレーキの踏み始め位置、最低速度、アクセルを開けた位置、ギヤをお手本と比較し、改善点を最大3件
- **区間リピート**: ラップ全体と8区間(1〜2コーナー、S字・逆バンク、ダンロップ、デグナー、ヘアピン、200R〜スプーン、130R・シケイン、最終コーナー)から選択。区間の少し手前から**お手本と同じ速度で再スタート**し、「自動リピート」ONなら講評の7秒後に自動でやり直します。ベスト評価は保存されます

## 仕様書で「開発時に確定」とされていた項目の決定内容

| 項目 | 決定 |
|---|---|
| ステアリング方式 | 自動操舵 (プレイヤーは操作しない)。追い越し時の進路取りも自動 |
| スライドパッド | 画面の左端いっぱいに1本。中央がニュートラル、右がアクセル、左がブレーキ (設定で入れ替え可) |
| 指を離したとき | ゼロに戻すを標準(設定で保持も可) |
| 変速の再現 | シフト時間 0.11秒の駆動切れ、オーバーレブになるシフトダウンは拒否 |
| 車両性能 | 約680ps / 13,600rpm、乾燥重量 505kg、最高速 約300km/h、ソフトタイヤで 1分42秒前後 |
| 雨 | 路面の濡れ具合(0〜100%)を連続値で計算。スリックとレインの性能は濡れ約40%で逆転 |

## オリジナル版 (架空サーキット)

実在のサーキットを使わない別バージョンです。標準版と同じゲームを、本作で設計した架空の3コースで遊べます。自車 (OK RACING) は水色のカラーリングで、アイコンとUIのアクセント色も水色です。標準版とは別アプリ (`jp.okracing.original`) なので、両方を並べて入れられます。

- APK: `release/FormulaSimulatorOriginal-1.1.4-debug.apk`

| コース | 全長 | 性格 | 元にした既存コースの性格 |
|---|---|---|---|
| ベイサイド・スーパースピードウェイ | 3,988m | ホームベース形の変形オーバル。左回り、5ターン (90°ターンは半径190m、45°ターンは半径280m)、ターンにバンク (約6〜9°)。薄いウイングのスーパースピードウェイ仕様で、どのセッティングでもターン手前でアクセルを戻す必要がある | インディ |
| ミストラル・テクニカルパーク | 4,843m | 曲線主体の低速テクニカルコース。右回り、13コーナー。2つの半径を持つ複合コーナー (1・10・最終)、3速で抜けるS字、コースの内側へ入り込む鈴鹿と同じ半径20mの左ヘアピン。低速寄りのセッティングがわずかに有利 | 鈴鹿 (S字・ヘアピンの要素) |
| ホライゾン・ハイスピードサーキット | 5,768m | 約1.4kmのメインストレートと高速・中速コーナー。右回り、10コーナー。高速寄りのセッティングが有利 | 富士 (長いメインストレート) |

コースの形は実在のサーキットの図面・測量データ・地図データを使わず、`tools/build-original.mjs` で直線と緩和曲線つきの円弧を並べて設計しています (旋回角と位置の閉合は自動で合わせる)。

- ビルド: `npm run build:original` (→ `dist-original/`)、APK は `cd android && gradle -Pvariant=original assembleDebug`
- テスト: `npm run test:original`
- コースを作り直す: `node tools/build-original.mjs` → `node tools/build-line.mjs 400 <コースid> original` (レーシングライン)
- 版ごとの違いは `src/variant.js` (標準版) と `src/variants/original/` (オリジナル版の設定・コース定義・データ・アイコン) にまとめてあり、ビルド時に差し替わります。オリジナル版のビルドは、実在のサーキット名が含まれていると失敗します。

## 実機テスト (adb で接続した端末)

`tools/device-test.mjs` は、Mac などに USB でつないだ Android 端末でゲームを長時間自動で動かし、記録を残します (Node.js 22 以上と adb が必要)。デバッグ版の APK は WebView のリモートデバッグが有効なので、スクリプトがゲームの中身を操作・計測できます。

```
node tools/device-test.mjs --minutes 60 --apk release/FormulaSimulator-1.3.14-debug.apk --llm http://127.0.0.1:8080/v1 --model <モデル名>
```

- 3 コースで フリー走行 / トレーニング / 決勝 を自動運転で順に回し、最後に adb のタッチでペダルとパドルを実際に操作する
- 15 秒ごとにフレームレート・状態・JS エラー、1 分ごとに端末のメモリと温度、5 分ごとにスクリーンショットを記録する
- 終了後に `device-test-<日時>/report.md` (要約) と `report.json` (全記録) を書き出す。`--llm` を付けるとローカル LLM (OpenAI 互換 API) に要約を渡して分析させ、`report-llm.md` に保存する (`--llm-images` で画像も送る)
- オリジナル版は `--variant original` (オリジナル版のデバッグ版 APK を入れておく)

## 開発

```
npm install        # esbuild のみ
npm run dev        # 開発サーバー (ビルド不要、ES Modules のまま動く)

npm run build      # dist/ に単体版を出力
cd android && gradle assembleDebug   # APK (要 Android SDK。先に npm run build)
```

## 富士スピードウェイのデータ

提供されたコース図(画像)から `tools/build-fuji.py` で生成しています。

1. コース図の青い線を画像処理で読み取り、走行順に並べる(細いピットレーンの線は除外)
2. 全長 4,563m に合わせる
3. 図に書かれたコーナー半径(27R、15R など)に合うよう、各コーナーの曲率の山を均す。旋回角は図のまま保ち、生じた閉合誤差は距離に比例して全体へ配る
4. 標高グラフを読み取って高低差にする

| コーナー | 図の半径 | データ |
|---|---|---|
| TGR | 27R | 27R |
| コカ・コーラ | 80R | 81R |
| トヨペット100R | 105 / 100 / 95R | 113 / 101 / 93R |
| アドバン | 30R | 30R |
| ダンロップ | 15 / 30 / 60R | 15 / 29 / 67R |
| 第13 | 45R | 44R |
| レクサス | 25R | 26R |
| パナソニック | 33R | 32R |

測量データではないので形状は近似です。300R 付近の緩いカーブ(165R・230R)は図より小さめの半径(約140R)になっています。幅員は図の「15〜25m」に合わせ、メインストレートを 25m、その他を 15m としています。ピットレーン・縁石・ランオフ・スタンドの配置は本作で付けたものです。

理想ラインは `node tools/build-line.mjs 400 fuji` で再計算できます。サーキットの定義(区間名、ピット位置、練習区間など)は `src/tracks.js` にまとまっています。

## コースデータとライセンス

- コース中心線・幅員: [TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database) (LGPL-3.0、`third_party/LGPL-3.0.txt`)。中心線の原データは © OpenStreetMap contributors (ODbL)。
- 元データを 5,807m に正規化し、局所的な折れを平滑化(元データとのずれは平均 約0.5m)。高低差は公開情報をもとにした近似プロファイルです。
- コースは現行レイアウトです(1990年当時とは 130R とシケインの形状が異なります)。
- チーム名・ドライバー名・マシンはすべて架空で、実在のチーム・主催者・サーキット運営者とは関係ありません。
